1서비스 흐름 — 게임 속 행동이 ‘나의 근거’가 되고, 다시 현실 행동으로 이어진다

STEP 1

PLAY

고장 난 작업실·다리 건축가·하루 상점·위기 대응 센터·마을 중재소. 혼자 탐색은 10분, 문제마다 최대 3번 시도, 넘어가기 가능.

현재 구현
STEP 2

OBSERVE

해결 품질·풀이 시간·재도전·직접 실험·선택 변경·중도 이탈과 플레이 후 2문항(다시 하고 싶은지·부담감) 기록.

현재 구현
STEP 3

DISCOVER

CAN·LIKE·TRY·AVOID 분리, 근거 타임라인, 근거를 인용하는 AI 자기이해 리포트.

현재 구현
STEP 4

EXPLORE

관찰된 직무 행동이 쓰이는 직업을 적합도 없이 제시. 직업 DB는 12개 샘플.

구현 공공 API 예정
STEP 5

REAL QUEST

게임 밖 20분 미션. 개발자 Lv.1·Lv.2 심화, 그 외 직업은 AI 맞춤 탐색 미션. 결과가 다시 근거로 저장.

현재 구현

↺ REAL QUEST 결과는 근거 보관함에 다시 쌓입니다 · 상시 ‘도움 연결’(109 · 1577-0199 · 129 · 1388) · 기록 활용 동의 · 본인 기록 삭제

2실제 서비스 화면 — PLAY 모두 운영 중인 서비스의 캡처 (닉네임은 테스트 계정)

모든 게임 화면에 “틀려도 괜찮아요 — 다시 시도, 방법 바꾸기, 직접 실험 모두 TRY 근거로 기록돼요”가 표시됩니다. 점수·순위가 아니라 과정을 기록하는 것이 기존 진로 검사·경쟁형 게임과의 차이입니다.

왜 이 구조인가 — 사회현안과의 연결

  • 진입 장벽 최소화: 대면·신청·검사지 없이 집에서 익명 닉네임으로 한 판(약 10분)부터 시작합니다.
  • 낙인 없는 자기이해: 못하는 것을 찾지 않고, 덜 끌리는 방식(AVOID)도 ‘선호 정보’로 존중합니다. AI 시스템 프롬프트에 진단·적합도·규정 금지를 명시했습니다.
  • 재고립 방지: 근거 → 직업 탐색 → 게임 밖 REAL QUEST로 작은 실천을 반복하고, 힘들 때는 공공 상담 창구로 바로 연결합니다.

신뢰·안전 설계 현재 구현

  • 서버 권위 검증 — 카운트다운 전·중복·지연 제출 거부, 시간 종료 시 근거 없는 XP 미지급, 잘못된 재료 거부.
  • 개인정보 — 동의 없이는 프로필 생성 불가, 익명 토큰은 해시로 저장, 행동 기록·리포트는 본인 소켓에만 전송, 본인 기록 삭제 가능.
  • AI 사용 — 가명 요약만 입력, 프롬프트에 진단·적합도·규정 금지와 근거 인용 의무, 실패 시 규칙 기반 대체(횟수 미차감), 성공 생성만 계정당 10회.
  • 남용 방지 — 소켓 초당 20회, 메시지 16KB, IP당 분당 30세션, AI 15초 간격, CSP·Origin 검사.

분면판정 규칙 (게임 단위, insight.js)
CAN완료 판의 평균 해결 품질 ≥ 75%
LIKE‘다시 해보고 싶다’ ≥ 4점, 또는 스스로 3회 이상 선택
TRY처음 틀린 뒤 재해결 ≥ 1 · 재도전 ≥ 2 · 직접 실험 ≥ 4 · 어려운 판 뒤 재도전 중 하나
AVOID의향 ≤ 2 · 부담 ≥ 4 · 최근 판 중도 이탈 중 하나 (약점이 아닌 선호 정보)
CAN “고장 난 작업실에서 2회 플레이 평균 해결 품질 90% — 조건을 충족하는 해결이 반복적으로 관찰됐어요.”
TRY “처음 틀린 문제 5개를 다시 시도해 해결했어요 (재도전 9회 · 직접 실험 1회).”
