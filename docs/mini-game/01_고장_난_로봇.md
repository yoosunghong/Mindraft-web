# TALLO 미니게임 콘셉트 기획서 — 고장 난 로봇을 구해라!

> 문서 상태: 메인 콘셉트 초안 | 대상: 고등학생~성인 | 플랫폼: 웹(PC·모바일)

## 1. 한 줄 소개
회로 회전 · 경로 최적화 퍼즐

## 2. 게임 콘셉트 및 목표
고장 난 로봇에 전력을 공급하기 위해 회로 타일을 90도씩 회전한다. 연결 가능한 경로는 여럿이지만 소비 전력, 필수 장치, 고장 부품 조건을 모두 만족해야 성공한다.

## 3. 핵심 재미
단순히 선을 이어 붙이는 것이 아니라 여러 경로의 비용과 위험을 비교해 최적의 연결을 찾는 재미.

## 4. 기본 플레이 흐름
1. 미션 브리핑에서 전력 예산과 필수 조건을 확인한다.
2. 타일을 클릭해 회로 방향을 회전한다.
3. 연결된 회로와 실시간 소비 전력을 확인한다.
4. `회로 검사`로 조건 충족 여부를 확인한다.
5. 실패 원인을 보고 수정하거나 성공 후 다음 단계로 이동한다.

## 5. 난이도 구성
- **하:** 복수 경로 중 9W 이하 경로 찾기.
- **중:** 13W 이하 + 배터리 필수 경유 + 전력 소모가 다른 부품.
- **상:** 17W 이하 + 배터리·냉각 장치 필수 + 고장 회로 우회.

## 6. 관찰할 역량
- **핵심:** 논리적 문제해결력
- **보조:** 복합 조건 처리, 경로 최적화, 전략 수정

## 7. 수집할 플레이 데이터
- 성공 여부 및 조건별 충족 여부
- 총 회전 횟수와 최소 필요 회전 횟수의 차이
- 검사 횟수와 검사 시점별 실패 사유
- 최종 전력 사용량 및 문제별 가능한 최적 전력
- 경로 변경 기록과 실패 이후 개선 정도

## 8. 비주얼·UX 방향
- 밝은 로봇 정비실, 흰색·연청색 타일, 전력 흐름은 청록색 발광.
- 고장 부품은 코랄색 경고, 전력 예산은 선명한 게이지로 표시.
- 로봇은 친근하지만 UI는 정돈된 연구실 장비처럼 구성.

## 9. 기획·분석 시 유의점
- 모든 퍼즐은 자동 풀이 검증으로 **해결 가능성**과 대안 경로를 확인한다.
- 분기된 모든 통전 부품이 전력을 소비한다는 규칙을 튜토리얼에서 명시한다.
- 빠른 클릭보다 조건 충족·개선 과정을 우선 분석한다.

## 공통 설계 원칙
- 대상: 고등학생~성인. 조작은 직관적이고 판단은 도전적으로 설계한다.
- 한 게임 약 2~4분, 난이도 하·중·상 각 1라운드로 구성한다.
- 성공 여부뿐 아니라 조작 순서와 수정 과정도 이벤트 로그로 수집한다.
- 플레이 기록은 역량 탐색의 단서이며, 단일 게임으로 적성·직무 적합도를 확정하지 않는다.
- 밝은 화이트·아이스블루 기반의 TALLO 브랜드 UI와 게임별 포인트 컬러를 사용한다.

## MVP 완료 기준
- 시작 전 15~25초 튜토리얼 및 조작 연습 제공
- 하·중·상 각 난이도에서 성공·실패·재도전 가능
- 결과 화면에 정확도, 소요 시간, 핵심 행동 피드백 표시
- 난이도, 문제 ID, 타임스탬프, 조작 이벤트, 결과 로그 저장
- 키보드/터치 조작과 색상 외 구분 수단 제공
