# TALLO 미니게임 콘셉트 기획서 — 우주 택배 정리왕

> 문서 상태: 메인 콘셉트 초안 | 대상: 고등학생~성인 | 플랫폼: 웹(PC·모바일)

## 1. 한 줄 소개
변형 테트리스 · 공간 배치 퍼즐

## 2. 게임 콘셉트 및 목표
우주선 화물칸에 다양한 모양의 택배 블록을 회전·이동해 빈 공간 없이 효율적으로 적재한다. 낙하 속도보다 형태 파악과 배치 선택에 초점을 맞춘다.

## 3. 핵심 재미
블록이 딱 맞아떨어지는 쾌감과, 한 수 앞을 읽어 빈 공간을 줄이는 재미.

## 4. 기본 플레이 흐름
1. 적재 공간과 이번 라운드의 블록 목록을 확인한다.
2. 블록을 드래그해 이동하고 버튼 또는 키로 회전한다.
3. 배치 확정 전에는 미리보기 그림자가 나타난다.
4. 모든 블록을 배치하거나 제한된 기회를 소진하면 결과를 확인한다.

## 5. 난이도 구성
- **하:** 4×4 공간, 블록 3개, 장애물 없음.
- **중:** 5×5 공간, 회전 필수 블록과 제한된 재배치 기회.
- **상:** 6×6 공간, 고정 장애물과 다양한 블록 모양, 빈칸 최소화 목표.

## 6. 관찰할 역량
- **핵심:** 공간지각력(형태 회전·위치 관계)
- **보조:** 공간 계획, 시각적 작업 기억(별도 기억 라운드 도입 시)

## 7. 수집할 플레이 데이터
- 블록 회전·배치 정확도
- 공간 활용률과 남은 빈칸 수
- 블록별 재배치 및 취소 횟수
- 최초 배치까지의 시간과 전체 완료 시간
- 난이도 변화에 따른 성공률

## 8. 비주얼·UX 방향
- 화이트·라벤더 기반의 밝은 우주 화물 터미널.
- 택배 블록은 색상뿐 아니라 기호·무늬로도 구분.
- 배치 성공 시 가벼운 자석 결합 효과와 만족스러운 사운드.

## 9. 기획·분석 시 유의점
- 순발력 위주의 자동 낙하보다는 **수동 배치형 테트리스**로 설계한다.
- 블록 조합마다 정답 가능 여부를 사전 검증한다.
- 공간 활용률은 퍼즐별 최적해와 비교하고 단순 속도만으로 평가하지 않는다.

## 공통 설계 원칙
- 대상: 고등학생~성인. 조작은 직관적이고 판단은 도전적으로 설계한다.
- 한 게임 약 2~4분, 난이도 하·중·상 각 1라운드로 구성한다.
- 성공 여부뿐 아니라 조작 순서와 수정 과정도 이벤트 로그로 수집한다.
- 플레이 기록은 역량 탐색의 단서이며, 단일 게임으로 적성·직무 적합도를 확정하지 않는다.
- 밝은 화이트·아이스블루 기반의 TALLO 브랜드 UI와 게임별 포인트 컬러를 사용한다.

## MVP 완료 기준
- 시작 전 15~25초 튜토리얼 및 조작 연습 제공
- 하·중·상 각 난이도에서 성공·실패·재도전 가능
- 결과 화면에 정확도, 소요 시간, 핵심 행동 피드백 표시
- 난이도, 문제 ID, 타임스탬프, 조작 이벤트, 결과 로그 저장
- 키보드/터치 조작과 색상 외 구분 수단 제공
