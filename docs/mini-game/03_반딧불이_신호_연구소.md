# TALLO 미니게임 콘셉트 기획서 — 반딧불이 신호 연구소

> 문서 상태: 메인 콘셉트 초안 | 대상: 고등학생~성인 | 플랫폼: 웹(PC·모바일)

## 1. 한 줄 소개
리듬 반응 · 순서 기억 게임

## 2. 게임 콘셉트 및 목표
밤의 숲에서 반딧불이가 보내는 빛 신호를 보고 알맞은 순서와 타이밍으로 입력한다. 난이도가 높아질수록 방해 신호와 규칙 전환이 추가된다.

## 3. 핵심 재미
음악과 빛이 맞아떨어지는 리듬감, 패턴을 정확하게 기억해 재현하는 성취감.

## 4. 기본 플레이 흐름
1. 4색 신호 버튼과 기준 박자를 연습한다.
2. 반딧불이의 점등 순서를 관찰한다.
3. 신호를 순서대로 입력하거나 박자에 맞춰 누른다.
4. 방해 신호가 나타나면 목표 신호만 반응한다.
5. 라운드별 정확도와 오류 유형을 확인한다.

## 5. 난이도 구성
- **하:** 3개 신호, 느린 박자, 방해 요소 없음.
- **중:** 5개 신호, 조금 빠른 박자, 비슷한 색·위치의 방해 신호.
- **상:** 7개 신호, 방해 신호와 중간 규칙 전환(예: 특정 신호 무시).

## 6. 관찰할 역량
- **핵심:** 순서 기억력, 선택적 주의
- **보조:** 반응 억제, 규칙 전환 적응

## 7. 수집할 플레이 데이터
- 순서 재현 정확도와 최대 정확 재현 길이
- 목표 신호 누락·방해 신호 오입력 횟수
- 박자 대비 입력 오차(리듬 모드)
- 규칙 전환 전후 오류율
- 반복 시도별 정확도 변화

## 8. 비주얼·UX 방향
- 민트·남보라·노란 빛이 어우러지는 환한 판타지 숲.
- 밤 배경이지만 전체 사이트의 밝은 테마와 연결되도록 채도와 대비를 조절.
- 색각 차이를 고려해 색상마다 기호와 위치를 함께 부여.

## 9. 기획·분석 시 유의점
- **기억 모드**와 **리듬 모드** 점수를 분리해 혼동하지 않는다.
- 기기 입력 지연과 음소거 환경을 고려해 시각 박자 가이드를 제공한다.
- 반응 속도가 빠르다는 이유만으로 집중력이 높다고 판단하지 않는다.

## 공통 설계 원칙
- 대상: 고등학생~성인. 조작은 직관적이고 판단은 도전적으로 설계한다.
- 한 게임 약 2~4분, 난이도 하·중·상 각 1라운드로 구성한다.
- 성공 여부뿐 아니라 조작 순서와 수정 과정도 이벤트 로그로 수집한다.
- 플레이 기록은 역량 탐색의 단서이며, 단일 게임으로 적성·직무 적합도를 확정하지 않는다.
- 밝은 화이트·아이스블루 기반의 TALLO 브랜드 UI와 게임별 포인트 컬러를 사용한다.

## MVP 완료 기준
- 시작 전 15~25초 튜토리얼 및 조작 연습 제공
- 하·중·상 각 난이도에서 성공·실패·재도전 가능
- 결과 화면에 정확도, 소요 시간, 핵심 행동 피드백 표시
- 난이도, 문제 ID, 타임스탬프, 조작 이벤트, 결과 로그 저장
- 키보드/터치 조작과 색상 외 구분 수단 제공
