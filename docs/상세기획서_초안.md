## □ 추진배경 및 목적

**ㅇ 현황·문제점**
- 일자리 밖 20~30대 158만 9천 명, 이 중 ‘쉬었음’ 71만 9천 명(2025.11., 11월 기준 역대 최대). 졸업 후 3년 이상 미취업 24만 1천 명(19.4%, 2026.5., 역대 최고). 미취업 청년의 25.3%는 ‘그냥 시간 보냄’.
- 거의 집에만 있는 고립·은둔 청년 5.2%, 가장 큰 이유는 취업 어려움(32.8%). 고립·은둔 청년의 75.4%가 자살을 생각했고, 80.8%는 벗어나길 원하지만 절반가량은 시도 후 다시 고립.
- 즉 **구직 단념 → 고립 → 정신건강 위기**로 이어지는 연쇄가 사회현안(은둔형 외톨이, 자살률 증가)이며, 정부도 「위기아동·청년법」(2026.3. 시행)으로 대응을 확대 중.
- 빈틈: 기존 지원은 본인 신청·대면 참여가 출발점이고, 진로 검사는 자기보고식 1회 결과지에 그침. 온라인에 머무는 청년이 **직접 해 본 경험으로 자신을 이해하고 작은 행동을 반복**할 저강도 경로가 부족.

**ㅇ 서비스 개발 목적**
1. 집에서 익명으로 5분이면 시작하는 **저강도 온라인 진입로** 제공
2. 검사 점수 대신 **행동 근거(CAN·LIKE·TRY·AVOID)** 로 자기이해 지원
3. 직업 탐색 → **REAL QUEST** 로 게임 밖 실천을 반복하게 하여 재고립 방지
4. 필요한 청년을 **청년미래센터·청년센터·고용센터**로 연결

## □ 개요

Mindraft는 5개 미니게임으로 ‘일의 방식’을 경험하게 하고, 행동 로그와 플레이 후 자기평가를 AI가 CAN·LIKE·TRY·AVOID로 나눠 **근거 보관함**에 쌓습니다. 관찰된 직무 행동이 쓰이는 직업을 적합도 없이 제시하고, 게임 밖 20분짜리 REAL QUEST로 현실 행동을 이끈 뒤 그 결과를 다시 근거로 저장하는 **순환 구조**입니다.

| 기존(As-Is) | Mindraft(To-Be) |
|---|---|
| 자기보고식 검사 1회 → 유형·적합 직업 | 직접 해 본 행동이 쌓일수록 근거가 선명해짐 |
| 점수·순위 중심, ‘못하는 것’ 노출 부담 | 점수·적합도 없음, AVOID도 ‘선호 정보’로 존중 |
| 기관 방문·대면 참여가 출발점 | 온라인·익명·한 판부터, 필요 시 기관 연결 |
| 정보 제공 후 종료 | REAL QUEST → 근거 재축적의 순환 |
| (기존 웹 데모) 90초 정확도·속도 경쟁, 능력치 XP | 혼자 탐색(재도전·넘어가기), 과정 로깅, 자기평가, 리포트, 직업 탐색, 퀘스트 추가 |

## □ 내용

**ㅇ 데이터 분석 방법·알고리즘**
- 수집: 문제별 해결 품질(0~1), 풀이 시간, 시도 횟수, 첫 시도 품질, 직접 실험 수, 선택 변경 수, 넘어가기, 중간 이탈, 협동 여부, 자기평가(다시 하고 싶음·부담감 1~5)
- 분리 규칙(게임 단위):
  - CAN = 평균 해결 품질 ≥ 0.75
  - LIKE = 재플레이 의향 ≥ 4 또는 자발적 선택 3회 이상
  - TRY = 처음 틀린 문제를 다시 해결 ≥ 1, 재도전 ≥ 2, 직접 실험 ≥ 4, 어려웠던 판 이후 재도전 중 하나
  - AVOID = 의향 ≤ 2, 부담 ≥ 4, 최근 판 이탈 중 하나
- 차이 발견: CAN이지만 LIKE가 아님 / TRY지만 아직 CAN이 아님 → “잘하는 것 ≠ 좋아하는 것”
- 직무 행동 점수: 게임별 행동 태그에 LIKE +1, TRY +1, CAN +0.6, AVOID −1(+기본 0.2), 재도전·퀘스트는 ‘반복 개선’·‘문제 기록’ 가산 → 직업별 행동 합 / √행동 수로 정렬(점수는 사용자에게 비공개)
- AI: 가명 요약 JSON만 입력, 시스템 프롬프트로 진단·점수·적합도·규정 금지, 근거 인용 의무, 900자 이내. 실패·거절 시 규칙 기반 리포트
- ☐ 검증 계획: 리포트 문장 중 근거 인용 비율, 금지 표현 검출 0건, 사용자 ‘나를 설명하는 데 도움’ 응답

**ㅇ 서비스 구현 예시 화면** — ☐ 캡처 삽입: 탐험 마을(5단계 여정) / 혼자 탐색 재도전 힌트 / 플레이 후 자기평가 / 근거 보관함(4분면·리포트·타임라인) / 직업 탐색 / 개발자 REAL QUEST Lv.2 / 도움 연결

**ㅇ 사용자 시나리오 (본선 시연 한 사이클)**
1. 졸업 후 1년째 집에 머무는 ‘우와’님이 닉네임으로 입장(기록 활용 동의)
2. 혼자 탐색 ‘고장 난 작업실’ → 두 문제를 처음엔 틀렸지만 직접 실험 후 다시 해결
3. 자기평가: 다시 해보고 싶음 5, 부담 2 → **TRY·LIKE 발견**, 근거 보관함 업데이트
4. ‘다리 건축가’는 해결 품질이 높지만 의향 1·부담 4 → **CAN이지만 AVOID**, 차이 표시
5. AI 리포트: “원인을 확인하고 다시 시도하는 행동이 반복 관찰됐어요…”
6. 직업 탐색: 원인 추적·가설 실험·반복 개선이 쓰이는 **소프트웨어 개발자** 탐색
7. REAL QUEST Lv.1(웹사이트 문제 재현 기록) → Lv.2(버그 원인 찾고 코드 수정) 완료 → 근거 추가
8. 힘들 때는 상단 ‘도움 연결’로 109·129·청년미래센터 안내

※ 최종 솔루션 및 서비스 구성도 — PLAY → OBSERVE → DISCOVER → EXPLORE → REAL QUEST → (근거 재축적) 순환도 + 기관 연결 분기

## □ 기대효과

- 청년: 경험 기반 자기이해 → 자기소개서·상담에서 “해 본 것”으로 자신을 설명, 작은 실천의 반복으로 재고립 방지
- 기관: 동의 기반 사전 탐색 기록으로 상담 시간 단축, 기존 제도(청년미래센터·청년도전지원사업·고용24)의 온라인 전 단계 확보
- 사회: 구직 단념 → 고립 → 정신건강 위기 연쇄의 초기 개입
- 성과지표: 첫 플레이 완료율, 자기평가 응답률, 7일 재방문율, REAL QUEST 완료율, 리포트 도움 응답률, 도움 연결 클릭 수 — ☐ 사용자 테스트 목표치 설정
- 확장: 직업군별 REAL QUEST(현직자 검수), 지역 청년센터 기관용 대시보드, 고용24 직업정보 전면 연동, 2027년 공공데이터 기반 조기발굴 체계와 연계
