# TALLO 미니게임 콘셉트 기획서 — 오늘은 내가 가게 사장!

> 문서 상태: 메인 콘셉트 초안 | 대상: 고등학생~성인 | 플랫폼: 웹(PC·모바일)

## 1. 한 줄 소개
주문 처리 · 수량 판단 아케이드

## 2. 게임 콘셉트 및 목표
작은 카페의 사장이 되어 주문 카드에 맞는 상품과 수량을 빠르고 정확하게 준비한다. 재고와 주문 우선순위가 더해져 간단한 운영 판단을 경험한다.

## 3. 핵심 재미
주문이 착착 처리되는 쾌감과 바쁜 상황에서 정확하게 선택하는 몰입감.

## 4. 기본 플레이 흐름
1. 손님의 주문 카드에서 상품·수량을 확인한다.
2. 진열대의 상품을 탭하거나 드래그해 주문 트레이에 담는다.
3. 완성 버튼으로 주문을 제출하고 다음 주문을 받는다.
4. 재고 부족·추가 주문 상황에서는 처리 순서를 선택한다.
5. 정확도, 누락, 처리 순서 결과를 확인한다.

## 5. 난이도 구성
- **하:** 한 번에 주문 1개, 상품 2종, 단순 수량 맞추기.
- **중:** 주문 2개 동시 표시, 합계 수량 계산, 제한 재고.
- **상:** 주문 3개, 재고 제한, 우선 처리 조건(예: 마감 임박 주문) 추가.

## 6. 관찰할 역량
- **핵심:** 수리적 판단(수량·재고), 우선순위 판단
- **보조:** 주의 전환, 작업 기억

## 7. 수집할 플레이 데이터
- 주문별 상품·수량 정확도
- 계산 오류와 주문 누락 횟수
- 재고 초과 시도 횟수
- 주문 처리 순서 및 마감 조건 충족률
- 수정 횟수, 처리 시간, 난이도별 정확도

## 8. 비주얼·UX 방향
- 크림·살구·하늘색의 산뜻한 카페 아케이드.
- 주문 카드는 간결하고 선명하게, 상품은 작은 3D 아이콘으로 표현.
- 연속 정확 처리 시 가벼운 콤보 효과를 제공하되 분석 점수와 분리.

## 9. 기획·분석 시 유의점
- 손님 응대 선택은 실제 대인관계 능력 측정으로 간주하지 않는다.
- 계산력과 빠른 손 조작을 구분하기 위해 정확도 중심의 별도 수량 문제를 포함한다.
- 시간 압박은 과도하지 않게 조절하고 연습 라운드를 제공한다.

## 공통 설계 원칙
- 대상: 고등학생~성인. 조작은 직관적이고 판단은 도전적으로 설계한다.
- 한 게임 약 2~4분, 난이도 하·중·상 각 1라운드로 구성한다.
- 성공 여부뿐 아니라 조작 순서와 수정 과정도 이벤트 로그로 수집한다.
- 플레이 기록은 역량 탐색의 단서이며, 단일 게임으로 적성·직무 적합도를 확정하지 않는다.
- 밝은 화이트·아이스블루 기반의 TALLO 브랜드 UI와 게임별 포인트 컬러를 사용한다.

## MVP 완료 기준
- 시작 전 15~25초 튜토리얼 및 조작 연습 제공
- 하·중·상 각 난이도에서 성공·실패·재도전 가능
- 결과 화면에 정확도, 소요 시간, 핵심 행동 피드백 표시
- 난이도, 문제 ID, 타임스탬프, 조작 이벤트, 결과 로그 저장
- 키보드/터치 조작과 색상 외 구분 수단 제공
