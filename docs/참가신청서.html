작품명

마인드래프트(Mindraft) — 게임 속 행동에서 ‘나의 근거’를 찾아, 고립·구직단념 청년을 다시 일과 사회로 잇는 AI 진로 탐색 서비스

작품 요약

1. 한 줄 소개

Mindraft는 사회와의 연결이 느슨해진 청년이 여러 ‘일의 방식’을 미니게임으로 부담 없이 경험하면, AI가 플레이 행동을 CAN(잘함)·LIKE(좋아함)·TRY(계속 시도함)·AVOID(부담)로 나눠 자기이해의 근거를 쌓아 주고, 이를 직업 탐색 → 게임 밖 작은 실천(REAL QUEST) → 공공 지원기관 연결로 이어 주는 웹 서비스입니다.

경험 → 행동 데이터 → 자기이해 → 직업 탐색 → 현실 행동 → 다시 근거 축적

2. 해결하려는 사회현안: 일자리 밖으로 밀려나 고립되는 청년

청년 고용 위기는 ‘구직 포기 → 고립·은둔 → 정신건강 위기’로 이어지는 사회적 재난형 현안입니다. 공모전 예시 주제인 ‘은둔형 외톨이’, ‘자살률 증가’, ‘지역소멸’과 직접 맞닿아 있습니다.

3. 제안 배경: 기존 방식의 빈틈

구분기존 진로·취업 지원Mindraft
자기이해 방식자기보고식 검사(고용24 직업심리검사, 커리어넷 진로심리검사 등) — 한 번 응답하면 결과지직접 해 본 행동을 기록 — 할수록 근거가 쌓임
결과 표현점수·유형·적합 직업 추천점수·적합도 없이 행동 근거 문장과 CAN·LIKE·TRY·AVOID 차이
진입 부담기관 방문·상담 신청, 대면 프로그램 중심(청년도전지원사업, 청년미래센터 등)집에서, 익명 닉네임으로, 한 판(5분)부터 — 온라인에 익숙한 고립 청년의 진입로
이후 행동정보 제공에서 종료되는 경우가 많음직업 탐색 → 게임 밖 REAL QUEST → 근거 보관함 재축적 → 필요 시 공공기관 연결

Mindraft는 기존 제도를 대체하지 않고, 공공 지원(청년미래센터·청년도전지원사업·고용24)에 닿기 이전 단계의 ‘저강도 온라인 진입로’이자, 참여 이후 동기를 이어 주는 도구를 목표로 합니다. 2026년 3월 시행된 「가족돌봄 등 위기아동·청년 지원에 관한 법률」에 따라 청년미래센터가 확대되는 흐름과도 맞물립니다.

4. 서비스 개요 (STEP 1~5)

단계사용자 경험AI·데이터
1. PLAY5개 미니게임으로 ‘일의 방식’ 경험: 원인 추리(고장 난 작업실), 조건 설계(다리 건축가), 수요 판단(하루 상점), 우선순위(위기 대응 센터, 협동 가능), 합의(마을 중재소). 혼자 탐색 모드는 문제마다 최대 3번 시도, 넘어가기 가능선택, 해결 품질, 풀이 시간, 재도전, 처음 틀린 뒤 해결, 직접 실험, 선택 변경, 이탈 기록
2. OBSERVE플레이 후 두 질문: “다시 해보고 싶나요?”, “얼마나 부담스러웠나요?”행동 로그 + 자기평가 → CAN·LIKE·TRY·AVOID 분리
3. DISCOVER나의 근거 보관함: 근거 타임라인, “잘하는 것 ≠ 좋아하는 것” 차이, AI 자기이해 리포트생성형 AI가 근거를 인용해 리포트 작성(진단·점수 표현 금지)
4. EXPLORE13가지 직무 행동이 쓰이는 직업 후보 탐색(적합도 % 없음)직무 행동 라이브러리 ↔ 직업 DB(고용24·커리어넷 직업정보 연계 예정)
5. REAL QUEST게임 밖 20분 실천. 개발자 심화 퀘스트: Lv.1 실제 웹사이트 문제 재현·기록 → Lv.2 버그 원인 가설 세우고 코드 한 줄 고치기. 그 밖의 직업은 AI 맞춤 탐색 미션사용자 기록을 반영한 미션 생성, 완료 결과가 다시 근거로 축적

안전망: 모든 화면에 ‘도움 연결’(109 자살예방, 1577-0199 정신건강위기, 129 보건복지상담·청년미래센터 안내)을 상시 제공하고, 운영 단계에서 지역 청년센터·청년미래센터 연계 경로를 둡니다.

5. 현재 개발 현황 (제출 시점 동작하는 MVP)

  • 상시 운영 주소: https://mindraft.yoosung.dev (Google Cloud Run 서울 리전에서 Node.js + Express + Socket.IO 운영, Cloudflare Worker로 도메인 연결, PC·모바일 브라우저 지원). 로컬 PC 가동 여부와 관계없이 접속할 수 있으며 프로필·행동 기록은 Cloud Firestore에 저장
  • 구현 완료: 5개 미니게임(1인 탐색 / 2~4인 실시간 함께 도전 / 협동), 행동 로깅, 플레이 후 자기평가, CAN·LIKE·TRY·AVOID 분석, 근거 보관함, Gemini 기반 AI 자기이해 리포트(AI 장애 시 규칙 기반 자동 대체), 13개 직무 행동 ↔ 12개 직업 탐색, 개발자 REAL QUEST Lv.1·2(서버 검증), 직업별 AI 맞춤 미션, Firebase Google 로그인과 계정당 AI 생성 10회 제한, 기록 활용 동의·가명 처리·본인 기록 삭제, 도움 연결
  • 품질: 자동화 테스트 21개(멀티플레이 동기화, 부정 제출 방지, 재도전 힌트의 정답 비노출, 퀘스트 검증, 삭제 등) 통과

6. 민관협력 지원 플랫폼 활용 계획

플랫폼 자원활용
민간 클라우드(Naver·KT·NHN Cloud 이용료 지원)현재 Google Cloud Run(서울)에 컨테이너 배포, Cloud Firestore와 HTTPS로 상시 접근 가능. 지원 플랫폼의 민간 클라우드는 운영비 최적화·백업·이중화에 활용 검토
서비스 API – 인공지능(언어분석 등)현재 Gemini API로 자기이해 리포트와 맞춤 REAL QUEST 생성(계정당 최대 10회, API 키는 Secret Manager에 보관). 지원 플랫폼의 AI API 연계도 검토
서비스 API – 간편 로그인·간편 인증Firebase Google 로그인으로 기록을 계정에 연결해 기기·브라우저가 바뀌어도 근거 보관함 유지(닉네임만으로 익명 이용도 가능). 지원 플랫폼 간편 로그인 API 연계 검토
서비스 API – 지도가까운 청년센터·청년미래센터·고용센터 안내
데이터 / 데이터 요청직업정보(고용24·커리어넷), 청년 정책·기관 목록 등 공공데이터 연계 요청
